## CBOR Structure Breakdown

### **1. Document Type (Key 57 - MobileSecurityObject)**

```cbor
{
  "docType": "org.iso.23220.1.academic"
}
```

- **Tag:** 57 (Mobile Security Object)
- **Value:** Type identifier for academic credential

### **2. Issuer Information**

```cbor
"issuerInfo": {
  "issuerName": "Smart College",
  "issuerDid": "did:example:issuer-001",
  "issuanceDate": "2026-08-28T20:58:43.832Z",
  "valueDigests": {
    "SHA256": {
      // Hash digests for all fields
    }
  }
}
```

**Purpose:** Identifies the credential issuer and provides integrity checks

### **3. Name Spaces (Data Elements)**

#### **3a. ISO/IEC 18013.5.1 (Standard Identity)**

```cbor
"org.iso.18013.5.1": {
  "givenName": "Alice",
  "familyName": "Johnson",
  "dateOfBirth": "2001-06-15",
  "studentId": "STU-2026-001"
}
```

**Elements:**
- `givenName` (Text String) - "Alice"
- `familyName` (Text String) - "Johnson"
- `dateOfBirth` (Date) - 2001-06-15
- `studentId` (Text String) - STU-2026-001

#### **3b. ISO/IEC 23220.1.Academic (Academic Data)**

```cbor

      "courseCode": "6.009",

    }

```

**Elements:**
- `institution` (Text String) - Institution name
- `degreeLevel` (Text String) - Level of degree
- `fieldOfStudy` (Text String) - Field of study
- `gpa` (Floating Point) - Grade point average
- `issuanceDate` (Date-Time) - When issued

- `achievements` (Array of Text Strings) - Honors and awards
- `courses` (Array of Objects) - Academic courses

## Verification Flow (Using CBOR mDOC)

### **1. Extract from QR Code**
```
Binary CBOR data → Decode → JSON structure
```

### **2. Verify Signature**
```
Data + Signature + Issuer's Public Key → ECDSA Verification → ✓ Valid
```

### **3. Hash Verification**
```
For each field:
  SHA256(field_value) == valueDigests["SHA256"][field_name]
```

### **4. Check Expiry**
```
Current Date < expiryDate → ✓ Valid
```

### **5. Validate Issuer**
```
issuerDid in trusted issuers registry → ✓ Approved
```

## How Verifiers Process CBOR mDOC

```
1. Scan QR Code
   ↓
2. Extract CBOR Binary
   ↓
3. Decode CBOR → JSON Structure
   ↓
4. Extract issuerDid: "did:example:issuer-001"
   ↓
5. Look up issuer in trusted registry
   ↓
6. Get issuer's public key
   ↓
7. Verify ECDSA signature using public key
   ↓
8. Verify value digests (SHA256)
   ↓
9. Check expiry date
   ↓
10. Verification Result: ✓ VERIFIED
```
