# Verifier Frontend

Web interface for employers/institutions to verify academic credentials.

## Overview

The Verifier Frontend provides:
- QR code scanner for wallet presentation
- Verification result display
- Verification history
- Policy configuration
- Audit log review
- Verifier profile management

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5174
